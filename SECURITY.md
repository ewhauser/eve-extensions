# Security policy

## Supported versions

Security fixes are made on the default branch and released as new package
versions. Only the latest published version of each package is supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting flow from the repository's **Security** tab so
the report, discussion, and any coordinated fix remain private until a release
is available.

Include the affected package and version, impact, reproduction steps, and any
suggested mitigation. You should receive an acknowledgement within seven days.
